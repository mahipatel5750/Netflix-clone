# 🎬 Netflix Clone

A responsive and interactive **Netflix-inspired streaming platform clone** built using **HTML, CSS, and JavaScript**.

This project recreates the look and feel of a modern streaming platform while implementing interactive features such as movie/show previews, search, FAQ accordion, My List, sign-in UI, profile menu, and more.

> ⚠️ This is a learning and portfolio project inspired by Netflix. It is not affiliated with or endorsed by Netflix.

## ✨ Features

### 🏠 Home Page
- Netflix-inspired landing page
- Responsive navigation bar
- Hero/banner section
- Trending Now section
- Modern dark UI

### 🎬 Trending Now
- Display of trending movies and shows
- Numbered ranking cards
- Horizontal carousel
- Left and right navigation buttons
- Interactive movie/show cards

### 🔍 Search
- Interactive search bar
- Search movies and shows by title
- Search using genres/tags
- Search using descriptions
- Clear search functionality

### 🎥 Show Preview
- Click on a movie/show to open its preview
- Dynamic title
- Movie/show tags
- Description
- Banner/poster image
- Add to My List option

### ▶️ Trailer Player
- Trailer/video player modal
- Play and close controls
- Dynamic show title
- Maturity information

### 🔐 Sign In
- Interactive Sign In modal
- Email input
- Sign-in interaction
- User name extraction
- Welcome message after signing in
- Sign-out functionality

### 👤 Profile
- Profile menu
- Dynamic user name
- Sign-in/sign-out state
- Profile avatar

### ➕ My List
- Add shows/movies to My List
- Remove items from My List
- My List count
- "In My List" state
- My List category filtering

### ❓ Frequently Asked Questions
- Interactive FAQ accordion
- Click to open an answer
- Click another question to close the previous one
- Animated plus icon

### 🌐 Language Selector
- Language selection UI
- Synchronized language selectors

### 📚 Help Center
- Interactive Help Center
- Multiple help articles
- Dynamic article content
- Close modal functionality

### 📱 Responsive Design
- Desktop-friendly interface
- Responsive layout
- Mobile-friendly components
- Flexible movie/show carousel
